🚀 Deploy Bridge to New Server

🐧 Linux Quick Deploy

Run this single command on your new Linux server:

curl -fsSL http://100.94.187.56:8888/install | SOURCE_SERVER=http://100.94.187.56:8888 MACHINE_NAME="your-server" WS_PORT=8766 bash

💡 The installer will prompt for your password (via sudo) when creating the systemd service.
🐛 Port 8766 automatically enables debug logging for troubleshooting.

🪟 Windows Quick Deploy

Run this command in PowerShell (as Administrator) on your new Windows server:

irm http://100.94.187.56:8888/install-windows | iex

💡 The installer will prompt for machine name and port configuration.
🔧 Requires Python 3.8+ and creates a Windows Service or Scheduled Task.
📦 Automatically installs pywinpty for Windows terminal support.

🗂️ FileMaker Bridge Quick Deploy

Run this single command on your Linux server to install FileMaker Bridge (port 8767):

curl -fsSL http://100.94.187.56:8888/filemaker-bridge-server.py -o ~/.filemaker-bridge/filemaker-bridge-server.py && mkdir -p ~/.filemaker-bridge && python3 ~/.filemaker-bridge/filemaker-bridge-server.py --machine-name "your-server" --port 8767

💡 FileMaker Bridge v1.1.0 runs separately on port 8767.
📊 Provides FileMaker Server Data API integration alongside Claude CLI.
🔧 Stores sessions in same database but tagged with session_type='filemaker'.

What It Does

  1. Downloads the bridge server from this machine
  2. Installs Python dependencies (websockets)
  3. Stops existing service if upgrading
  4. Creates systemd service with proper logging
  5. Configures machine name and WebSocket port
  6. Enables debug logging for port 8766
  7. Starts the bridge server automatically

Interactive Installation

The installer will ask for:

  • Machine Name - Friendly name (e.g., "Production Server")
  • WebSocket Port - Default is 8766
  • Confirmation - To proceed with install

After Installation on New Server

  1. The bridge will be running on the specified port (default: 8766)
  2. In your web terminal, click "➕ Add" connection
  3. Enter:
    • Name: The machine name you chose
    • Host: New server's IP
    • Port: 8766 (or what you chose)
  4. Connect and use!

Service Management

🐧 Linux (systemd):

sudo systemctl start claude-bridge # Start
sudo systemctl stop claude-bridge # Stop
sudo systemctl status claude-bridge # Status
sudo systemctl enable claude-bridge # Start on boot

🪟 Windows (PowerShell as Administrator):

Start-ScheduledTask -TaskName ClaudeBridge # Start
Stop-ScheduledTask -TaskName ClaudeBridge # Stop (if using Task Scheduler)
Get-ScheduledTask -TaskName ClaudeBridge | Get-ScheduledTaskInfo # Status
# Or if using NSSM:
nssm start ClaudeBridge # Start
nssm stop ClaudeBridge # Stop
nssm status ClaudeBridge # Status

View Logs

🐧 Linux: ~/.claude-bridge/bridge.log

tail -f ~/.claude-bridge/bridge.log # Follow logs in real-time
tail -100 ~/.claude-bridge/bridge.log # View last 100 lines
grep DEBUG ~/.claude-bridge/bridge.log # Filter debug messages

🪟 Windows: C:\ProgramData\claude-bridge\bridge.log

Get-Content C:\ProgramData\claude-bridge\bridge.log -Wait # Follow logs
Get-Content C:\ProgramData\claude-bridge\bridge.log -Tail 100 # Last 100 lines
Select-String -Path C:\ProgramData\claude-bridge\bridge.log -Pattern "DEBUG" # Filter
