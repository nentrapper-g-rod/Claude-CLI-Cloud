Personal Preferences
Configure personal preferences that Claude should consider in all responses. This will be added to the system prompt when starting any Claude session.
Example preferences: • I prefer direct, concise answers without excessive pleasantries
• When writing code, use descriptive variable names
• I work primarily with Python 3.11+ and modern JavaScript
• For web development, I prefer React with TypeScript
• Always include error handling in production code examples
• Use async/await instead of promises .then() syntax
Conversation Settings
Configure how your conversations are handled and stored.
When enabled, conversation history will not be automatically compacted by Claude. All messages will be preserved in their original form.
How It Works
When you start a Claude session from the terminal interface, your personal preferences will be automatically included in the system prompt. This helps Claude tailor responses to your specific needs and preferences without having to remind it every time.
