Setup Remote Claude CLI

1. Download Bridge Server

Download the Python bridge server script and run it on each machine you want to connect to:

2. Install Dependencies

On each remote machine, install required Python packages:

pip install anthropic aiofiles websockets

3. Run Bridge Server

Start the server on each machine:

python3 claude-bridge-server.py --machine-name "My Machine"

Set your Anthropic API key:

export ANTHROPIC_API_KEY="your-key-here"
